A fast, focused Kubernetes desktop IDE. Workloads, логи, метрики, Helm-релізи та топологія залежностей — в одному легкому застосунку.

Потужні можливості

Кластери, ресурси, YAML та Helm — спокійний локальний workflow без важкої панелі.

📦

Workloads

Pods, Deployments, Services, CRDs, RBAC, Nodes — з live-оновленнями через watch API.

📝

Логи + Термінал

Стрім логів з follow та вибором контейнера. Shell всередині будь-якого контейнера.

📊

Метрики

CPU/Memory нод та подів. Port-forward на localhost в один клік.

🔗

Helm

Релізи, values, manifests, notes та revisions без консолі.

🕸️

Topology

Граф залежностей workload з drill-down навігацією.

📝

YAML + Кластери

Перегляд, редагування та apply маніфестів з валідацією. Мультикластер kubeconfig.
